# Game Match Outcome Predictor

A machine learning system that predicts game match outcomes (win/draw/loss) using historical match data and statistical features.

## Features

- **Data Pipelines:** End-to-end pipelines covering data cleaning, preprocessing and feature engineering
- **Model Training:** Multiple ML models trained and compared to identify the most effective approach
- **Performance Evaluation:** Validated using accuracy scores and confusion matrix analysis
- **Extensible Design:** Structured to allow future integration with real-time data sources or APIs
